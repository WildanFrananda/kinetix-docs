## Tentang situs ini

Kinetix menjalankan katalog, checkout, pembayaran, fulfilment gudang, dan dispatch kurir sebagai
service yang berdiri sendiri. Setiap service memiliki datanya dan database-nya sendiri. Antar-service
berkomunikasi lewat gRPC, mengikuti kontrak yang didefinisikan sekali di `kinetix-contracts`. Trafik
dari luar masuk lewat satu Kong gateway, dan hanya identity yang berhak menentukan siapa pemanggilnya.

Halaman-halaman di sini menjelaskan kenapa sistemnya dibangun seperti itu, apa tanggung jawab tiap
service, dan kontrak di antara mereka. Setiap halaman ditulis berdasarkan kode yang dijelaskannya dan
menautkan kode itu pada commit tertentu, jadi yang kamu baca adalah yang berjalan.

## Service

| Service | Tanggung jawab | Bahasa |
| --- | --- | --- |
| [identity](https://github.com/WildanFrananda/kinetix-identity-service) | Akun, autentikasi, token, persetujuan merchant | TypeScript |
| [catalog](https://github.com/WildanFrananda/kinetix-catalog-service) | Produk dan kategori | Python |
| [pricing](https://github.com/WildanFrananda/kinetix-pricing-service) | Harga, diskon, voucher, flash sale, tarif ongkir | Rust |
| [order](https://github.com/WildanFrananda/kinetix-order-service) | Keranjang, checkout, pesanan, retur | C# |
| [payment](https://github.com/WildanFrananda/kinetix-payment-service) | Pembayaran, escrow, wallet | Java |
| [warehouse](https://github.com/WildanFrananda/kinetix-warehouse-service) | Inventori bin, reservasi stok, fulfilment task | Ruby |
| [matching](https://github.com/WildanFrananda/kinetix-matching-service) | Alokasi dan dispatch kurir | Elixir |
| [review](https://github.com/WildanFrananda/kinetix-review-service) | Ulasan produk | PHP |
| [notification](https://github.com/WildanFrananda/kinetix-notification-service) | Notifikasi pelanggan | Scala |
| [communication](https://github.com/WildanFrananda/kinetix-communication-service) | Chat real-time | C++ |
| [search](https://github.com/WildanFrananda/kinetix-search-service) | Pencarian produk | Go |

Di sekelilingnya ada [API gateway](https://github.com/WildanFrananda/kinetix-api-gateway) (Kong),
[aplikasi kurir](https://github.com/WildanFrananda/kinetix-courier-mobile) (Flutter), dan
[kontrak](https://github.com/WildanFrananda/kinetix-contracts) (Protocol Buffers) yang diikuti semua
service.
