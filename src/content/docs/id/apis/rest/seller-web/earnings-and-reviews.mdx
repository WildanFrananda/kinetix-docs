Penjual membaca hasil penjualannya dari payment dan pendapat pembeli tentang produknya dari review. Dompetnya
ditemukan lewat access token milik session, yang harus membawa role `seller`: session `customer` mendapat `403`
dari payment. Ulasannya ditemukan lewat `principalId` milik penjual dari
[Masuk](/id/apis/rest/seller-web/sign-in/), langkah 3. Review tidak membaca token untuk ulasan itu, tetapi lewat
edge setiap panggilan tetap memerlukan session.

## 1. Membaca dompet

Payment menahan bagian penjual dari setiap pesanan yang dibayar dan melepaskannya saat pesanan itu selesai;
jawabannya menampilkan kedua jumlah itu. Saldo adalah satu-satunya yang ditampilkan API REST payment kepada
penjual: tidak ada endpoint yang mendaftar pembayaran di baliknya
([WalletController.java](https://github.com/WildanFrananda/kinetix-payment-service/blob/146892d5305fcafe0e59f1230b6e1c7b5fe7cd27/modules/api/src/main/java/com/kinetix/payment/api/controller/WalletController.java#L21-L84)).

## 2. Membaca ulasan toko

`merchantPrincipalId` adalah `principalId` milik penjual. Halaman dihitung mulai dari 1: hilangkan `page`, atau
kirim `1`, untuk halaman pertama, lalu minta halaman berikutnya selama nilainya masih di bawah `last_page`.
