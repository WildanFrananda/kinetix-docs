The warehouse keeps one record per merchant, with the cutoff hour that decides whether a new order's parcel is
due the same day or the next. The seller reads the record, then sets the hour. Both calls need a session whose
role is `seller`, which an approved seller's session carries once the edge has renewed its tokens
([Become a seller](/apis/rest/seller-web/become-a-seller/), step 5).

## 1. Read the merchant record

Keep `id`, which steps 2 and 3 take. While `may_sell` is `false`, identity does not let the merchant trade, and
the hour cannot be changed.

<RestEndpoint id="warehouse.merchantMe" via="seller-web" />

## 2. Set the cutoff hour

Send the hour the seller chooses, with `id` from step 1. It applies to the tasks created from then on; each
task's due time shows in the packing queue as `same_day_cutoff_at`
([Pack orders](/apis/rest/seller-web/packing/), step 4).

<RestEndpoint id="warehouse.setCutoffHour" via="seller-web" />

## 3. Or set it with `PUT`

`PUT` on the same path reaches the same action as step 2. A client uses one of the two methods.
